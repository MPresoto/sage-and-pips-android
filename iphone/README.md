# Sage & Pips for iPhone

This installable web app keeps the Sage & Pips pixel-art actions, care meters, sounds, and offline files in one lightweight page.

## Install on iPhone

1. Open the published site in **Safari**.
2. Tap **Share** (the square with the arrow).
3. Tap **Add to Home Screen**, then **Add**.

Open Sage & Pips from its new Home Screen icon. After the first visit, the artwork and sounds are cached for offline use.
